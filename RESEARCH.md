## Compatibility boundaries that affect implementation

The original UCanAccess documentation describes Access data types, DML, transactions, Access functions/date literals/wildcards, saved SELECT/crosstab execution, complex values, and DDL. It also explicitly identifies ignored **data macros** and limited multiprocess access. These are inherited discovery leads, not current-fork regression results. In particular, changing a table while silently skipping its data macros would not reproduce Access behavior. [Driver documentation](https://ucanaccess.sourceforge.net/site.html).

Jackcess documents read/write formats 2000–2019 and Access 97 read-only, validation/default expressions, unique indexes, referential integrity, and no input-mask handling. An `.accdb` extension alone does not establish support for all modern field variants. Jackcess reads saved query definitions but does not execute SQL; UCanAccess supplies execution. [Jackcess FAQ](https://jackcess.sourceforge.io/faq.html).

The pinned fork `Database` API exposes table metadata, relationships, system tables, and `getQueries`; it does not expose full form/report/VBA editing APIs. No public high-level saved-query writer was found in the bounded tagged-source inspection. The engine's native saved SELECT implementation therefore needs its own close/reopen evidence and a later Windows QueryDef comparison. [Database API source](https://raw.githubusercontent.com/spannm/jackcess/jackcess-5.1.7/src/main/java/io/github/spannm/jackcess/Database.java).

Jackcess 5.1.7's default resolver disables automatic links. UCanAccess layers its own local-link handling and rejects remote/UNC links by default. Copying a frontend alone does not copy its linked backends. This application must reject linked databases until it supports explicit copied dependencies; otherwise edits could reach originals. [LinkResolver source](https://raw.githubusercontent.com/spannm/jackcess/jackcess-5.1.7/src/main/java/io/github/spannm/jackcess/util/LinkResolver.java), [UCanAccess linked-files documentation](https://github.com/spannm/ucanaccess/blob/ucanaccess-5.1.8/README.md).

Encryption companion discovery includes RC4 and standard/agile AES codecs, a password callback, and Bouncy Castle dependencies; arbitrary external-provider encryption is excluded. A password entry box alone is not encryption support. Encrypted files remain explicitly unsupported here. [Encryption companion README](https://raw.githubusercontent.com/spannm/jackcess-encrypt/jackcess-encrypt-5.1.6/README.md).

## SQL verification plan

Microsoft documents dialect differences including wildcard mode, `PARAMETERS`, `TRANSFORM`, aggregate functions, and reversed `Between` bounds. UCanAccess accepting both wildcard alphabets can be more permissive than a selected Access mode. Test **results and rejected syntax**, not just parsing. [Microsoft Access SQL vs ANSI SQL](https://learn.microsoft.com/en-us/office/client-developer/access/desktop-database-reference/comparison-of-microsoft-access-sql-and-ansi-sql).

Required fixtures: dates/timezones and ambiguous date literals; null/zero-length strings and `Nz` types; Boolean/AutoNumber/Currency/Decimal; brackets/reserved identifiers; nested joins and duplicates; `GROUP BY`/`HAVING`; `DISTINCT`; subqueries; `IIf` evaluation/errors; ANSI-89 vs ANSI-92 wildcard settings; parameter types; crosstabs; transactions/rollback; native saved QueryDefs; supported/unsupported DDL; linked, complex, encrypted, and macro-bearing databases. Generated native fixtures prove a limited subset locally. Windows reference results and application-object preservation must remain separate checks.

## Application-object representations

Native tables and system records are not a complete portable application model. Microsoft documents `Application.SaveAsText`/`LoadFromText` for exporting and importing forms, reports, macros, modules, and queries using **Access itself**. These exports are promising inspectable fixtures; this application does not currently parse or round-trip them. [SaveAsText](https://learn.microsoft.com/en-us/office/client-developer/access/desktop-database-reference/application-save-as-text).

Microsoft's **MS-ACCDT** specification describes an Access **template** representation with schemas, data, views, actions, and application metadata. It is not proof that arbitrary `.accdb` form/report/VBA internals are fully specified or handled by Jackcess. `.accde` compilation also removes editable source/design capabilities. A bounded experimental structural form/report inspector is now implemented; full semantic codecs and application execution are not established. See REA_FINDINGS.md for actual record offsets, preservation checks and limits. [Template specification](https://learn.microsoft.com/en-us/openspecs/sharepoint_protocols/ms-accdt/0a4a68d7-7a85-4a27-ad74-730db57862d7), [deployment formats](https://support.microsoft.com/en-us/access/deploy-an-access-application).
